# DeepSeek-Markdown-Tampermonkey
DeepSeek 聊天记录导出工具 (Tampermonkey)： 一键将 DeepSeek 网页版聊天记录导出为规范的 Markdown 文件，保留代码块、格式，自动生成可跳转目录。
解决deepseek聊天记录导出难题，帮助你构建本地知识库，或者在其他AI中继续聊天。

功能特点
🖨️ 打印渲染，完整捕获：利用打印预览触发虚拟滚动渲染，一次性加载全部历史消息，无需手动滚动

📑 智能目录：自动生成带有序号的消息目录，每条用户消息显示 100 字符摘要，点击即可跳转

🧹 自动过滤：自动剔除“已思考”内容和“本回答由 AI 生成”提示，保持对话纯净

💻 完整格式：代码块带语言标记，列表、加粗、引用等格式完整保留

👤 身份标识：用户消息显示 👤，DeepSeek 回复显示 🤖，一目了然

📁 一键导出：点击按钮 → 打印预览 → 关闭预览 → 自动下载 .md 文件

安装步骤
安装 Tampermonkey
访问 Tampermonkey 官网，安装对应浏览器的扩展（支持 Chrome、Edge、Firefox 等）。

添加脚本

点击 Tampermonkey 图标 → “管理面板” → “添加新脚本”

清空编辑器中的默认代码

粘贴下方脚本代码，按 Ctrl+S 保存

确认启用
确保脚本列表中该脚本处于“已启用”状态（复选框打勾）。

使用方法
打开 DeepSeek 聊天页面（chat.deepseek.com），进入任意对话。

等待页面加载完成，右上角会出现蓝色 “📄 导出 (打印渲染)” 按钮。

点击按钮，浏览器会自动弹出打印预览窗口。

等待打印预览加载完成（所有消息缩略图完整显示，根据对话长度可能需要几秒）。

按 Esc 键或点击“取消” 关闭打印预览。

脚本会自动处理并下载 .md 文件，文件名格式为 DeepSeek_Chat_YYYY-MM-DD.md。
